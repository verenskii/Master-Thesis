# Master-Thesis 
Recombinant protein production in *Escherichia coli* is frequently limited by protein misfolding and IB (Inclusion Body) formation, particularly for Difficult-to-Express (DtE) proteins. One such enzyme is  Alcohol-Dehydeogenase (ADH-A) from *Rhodococcus ruber*, which has significant industrial potential but exhibits poor soluble expression. This study combined systems-level computational modelling with experimental bioprocess development to identify factors limiting ADH-A folding and production. Protein folding and  availability were investigated using Stochastic Petri Nets (SPN) and metabolic modelling, respectively, and model predictions were validated experimentally during process scale-up from 50 mL shake flask cultivations to 20 L bioreactor cultivations using both the original production strain and an ALE strain selected for alkaline tolerance. The results identified oxygen availability as a major factor of ADH-A activity, consistent with computational predictions linking oxygen availability to intracellular ATP supply. Consequently, controlled bioreactor cultivations achieved higher volumetric enzyme activities than shake flask cultures. Furthermore, the ALE strain consistently exhibited superior growth across all pH conditions and cultivation formats, suggesting that adpative laboratory evolution (ALE) improved not only alkaline stress tolerance but also resilience to the metabolic burden associated with recombinant protein production. Medium composition, including the choice of bacto tryptone and calcium supplementation, also influenced growth performance. Overall, this work demonstrates how integrating systems-level modelling, adaptive laboratory evolution, and bioprocess optimisation can identify physiological bottlenecks and improve recombinant protein production.

## Statistical Methods
Means and standard deviations were calculated from biological replicate samples. Statistical significance between groups was assessed using the pairwise Welch's t-test, which does not assume equal variances between groups. When multiple pairwise comparisons were performed, p-values were adjusted using the Holm correction method to control the family-wise error rate. Statistical analyses were conducted in Python using the SciPy v1.13.1 and statsmodels v0.14.6 packages. Statistical significance was defined at three levels: *p* ≤ 0.05, *p* ≤ 0.01, and *p* ≤ 0.001.

## Repository Contents

This repository contains a representative selection of the programming work conducted as part of the thesis, including Python notebooks, experimental data, statistical analyses, and figure generation. The files provided illustrate the main data processing and analysis workflows but do not include all notebooks or raw datasets used throughout the thesis.

| Directory | Description |
|---|---|
| `bioreactor online data` | Contains Python notebooks for importing, cleaning, and processing online process data recorded during bioreactor cultivations. The processed data are used to generate figures for inclusion in the thesis. |
| `Enzyme Activity` | Contains Python notebooks and selected raw experimental data from shake flask and bioreactor cultivations. The notebooks process growth, ADH-A enzyme activity, and protein quantification data, calculate volumetric and normalized enzyme activities, perform statistical significance testing to compare strains, cultivation conditions, and cultivation formats, and generate thesis-ready figures. |
| `lysis Optimisation` | Contains a Python notebook for combining experimental data from cell lysis optimization experiments, performing statistical significance testing, and visualizing the results in thesis-ready figures. |
| `metabolic Modelling` | Contains Python notebooks for processing flux variability analysis (FVA) results and generating thesis-ready figures, along with the corresponding raw data (CSV files) obtained from analyses performed in MATLAB. |
| `protein Folding Modelling (SPN)` | Contains selected Python notebooks and raw data (CSV files) from protein folding simulations using a stochastic Petri net (SPN) model. The notebooks process simulation results, calculate means and standard deviations, and generate figures for inclusion in the thesis. |
